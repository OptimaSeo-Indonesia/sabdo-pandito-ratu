# Sabdo Pandito Ratu UI/UX Design System

This directory contains the complete visual identity of Sabdo Pandito Ratu.

Every UI task **MUST** start by reading this directory.

---

## Implementation Order

1. `philosophy.md` — Core identity and metaphor
2. `visual-language.md` — Design principles and visual direction
3. `reference-spec.md` — Approved visual reference (overrides personal decisions)
4. `layout-spec.md` — Grid, page structure, council positioning
5. `spacing-sizing.md` — Margins, padding, component sizes
6. `typography.md` — Font stack, sizes, weights, hierarchy
7. `colors.md` — Full color system (dark + light, advisor, connection)
8. `glassmorphism.md` — Glass effect specifications
9. `background.md` — Aurora, Gunungan, particles, neural grid
10. `components.md` — All reusable components
11. `council.md` — AI Council Chamber specification
12. `deliberation.md` — Live deliberation timeline
13. `verdict.md` — Verdict dashboard
14. `motion.md` — Animation specifications
15. `responsive.md` — Mobile and tablet adaptations
16. `implementation-rules.md` — Mandatory implementation rules
17. `visual-qa.md` — Visual QA checklist

---

## Mandatory Instruction

Never invent a new visual language.
Never redesign existing components.
Every page must conform to this design system.

**Consistency has higher priority than creativity.**

Before committing any UI change, run the Visual QA checklist (`visual-qa.md`).
