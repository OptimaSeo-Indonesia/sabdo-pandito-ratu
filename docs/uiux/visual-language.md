# Visual Language

## Theme

**AI Operating System**

## Mood

Premium · Futuristic · Elegant · Calm · Intelligent · Transparent

## Keywords

Glass · Glow · Neural · Council · Deliberation · Motion · Wisdom

## Design Principles

The UI must communicate:
- Wisdom
- Transparency
- Intelligence
- Trust
- Fairness
- Deliberation
- Reflection
- Premium Quality
- Calmness
- Precision

## Visual Inspiration

Inspired by: Linear, Raycast, Vercel, OpenAI, Arc Browser.

Sabdo Pandito Ratu must establish its **own** visual identity — never become a visual copy.

## What to Avoid

- Bootstrap appearance
- Generic SaaS landing pages
- ChatGPT clone
- Material Design defaults
- CRUD dashboards
- Marketing-heavy layouts
- Generic AI chat interfaces
