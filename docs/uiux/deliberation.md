# Deliberation

## Pipeline

Never display a spinner. Never show "Loading...".

Instead, visualize the 9-step deliberation pipeline:

1. Context Analysis
2. Perspective Generation
3. Argument Collection
4. Conflict Resolution
5. Ethical Review
6. Scenario Exploration
7. Reflection
8. Wisdom Scoring
9. Verdict Generation

## Timeline Component

- Vertical timeline with icons per step
- Line fills from top as steps complete
- Each step: icon + label + status indicator
- States: pending (dim icon), in_progress (spinner + glow), completed (checkmark + green)

## Live Advisor Activity

Every advisor visibly works with:
- Changing status text
- Progress bar filling
- Connection lines animating

## Experience Goal

Users should feel they are observing real deliberation — not waiting for a response.
