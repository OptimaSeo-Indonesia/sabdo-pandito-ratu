# Reference Motion & Animation

## Duration

All animations: **300–500ms** default.

## Hover Effects

- Translate Y: **-4px** on hover
- Glow intensifies on hover
- Soft shadow lift

## Breathing Animations

- Council nodes: subtle pulse (slow)
- Neural lines: moving gradient along stroke
- Aurora: very slow movement (8s+ cycle)
- Particles: floating, drifting

## Council

- Core: gentle pulse
- Advisor nodes: status-specific animation
- Connections: animated gradient flow

## Timeline

- Each stage animates independently
- Smooth transitions between stages
- Progress bars fill with animated width

## Page Transitions

- Entry: fade up, 400–600ms
- Route changes: fade in
- All animations feel calm, never flashy

## Key Principles

- Duration: 300–500ms
- No flashy animations
- Everything intentional
- Motion communicates state
