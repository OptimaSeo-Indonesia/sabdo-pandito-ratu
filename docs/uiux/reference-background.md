# Reference Background Specification

The background consists of **6 layers**.

## Layer 1: Dark Gradient

```
Top:    #0B1020
Bottom: #04060A
```

Very dark. No solid black.

## Layer 2: Aurora

- Very soft
- Blue and purple tones
- Opacity: 15%
- Large blur
- Slow animation

## Layer 3: Neural Grid

- Very subtle
- Opacity: 3%
- Thin lines
- Grid pattern

## Layer 4: Gunungan

- SVG, center aligned
- Outline only, no fill
- Gold color
- Opacity: 2–4%
- Blur: 2px
- Users should almost not notice it

## Layer 5: Floating Particles

- Radius: 2px
- Opacity: 15%
- Animation: slow, floating

## Layer 6: Radial Glow

- Center positioned
- Blue to purple
- Very soft
- Behind council area
