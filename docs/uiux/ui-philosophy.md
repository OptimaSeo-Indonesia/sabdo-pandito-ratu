# UI Philosophy

## Core Identity

Sabdo Pandito Ratu is a Multi-AI Deliberation Engine.

Users interact with an intelligent council, not a chatbot.

The interface reflects: wisdom, transparency, deliberation, trust.

## Experience Goal

Users should feel they are witnessing an AI council think.

Every visual decision reinforces: "this is not another AI chatbot."

## Metaphor

Council Chamber. Six advisors (pandito) sit in sacred formation around a wisdom core. Neural connections flow between them. Deliberation is visible, transparent, ceremonial.

## Background Symbolism

The Gunungan (Javanese mountain/tree) represents the cosmic tree of life — wisdom rooted in tradition, reaching toward the future. It appears at 2-5% opacity, discovered naturally, never distracting.
