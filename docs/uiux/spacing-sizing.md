# Spacing & Sizing

## Page Padding

| Breakpoint | Padding |
|------------|---------|
| Mobile (<640px) | px-4 (16px) |
| Tablet (640–1024px) | sm:px-6 (24px) |
| Desktop (>1024px) | lg:px-8 (32px) |

## Vertical Spacing

| Element | Margin |
|---------|--------|
| Hero to Council | mt-4 (16px) |
| Council to Input | mt-6 (24px) |
| Sections | mb-10 / mt-10 (40px) |
| Section title to content | mb-4 (16px) |
| Card padding | p-5 to p-6 |
| Between cards | gap-4 / gap-6 |

## Component Sizes

| Component | Size |
|-----------|------|
| Council container (full) | max-h-[560px], aspect-[4/5] |
| Council container (compact/sidebar) | max-h-[380px], aspect-[4/5] |
| Advisor node icon | h-14 w-14 → sm:h-16 w-16 |
| Core node | h-14 w-14 → sm:h-16 w-16 |
| Nav height | h-16 (64px) |
| Footer padding | py-8 (32px) |
