# Color System

## Dark Mode CSS Variables

```
--background:        240 10% 3.9%    (near-black)
--foreground:        0 0% 98%        (white)
--card:              240 10% 5.9%    (dark surface)
--primary:           239 84% 67%     (indigo)
--primary-400:       239 54% 45%     (darker indigo)
--primary-600:       239 70% 62%     (lighter indigo)
--border:            240 4% 16%      (subtle border)
--muted:             240 4% 16%
--muted-foreground:  240 5% 65%      (gray text)
--success:           160 84% 39%     (emerald)
--warning:           38 92% 50%      (amber)
--destructive:       0 63% 31%       (rose)
```
